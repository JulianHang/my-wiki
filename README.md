我的知识库

# 目录说明

这个知识库按“先收集、再整理、可复用、可追溯”的方式组织。

| 目录 | 用途 |
| --- | --- |
| `临时收集/` | 临时收集，还没有来得及整理的内容。 |
| `项目笔记/` | 项目笔记，和具体项目、仓库、任务或问题绑定。 |
| `技术专题/` | 技术专题，长期有效、跨项目复用的知识。 |
| `操作手册/` | 操作手册，可以重复执行的步骤化文档。 |
| `决策记录/` | 决策记录，说明重要选择及其原因。 |
| `片段库/` | 片段库，存放命令、SQL、curl、配置和代码片段。 |
| `文件附件/` | 图片、截图、PDF 和其他附件。 |
| `笔记模板/` | 常用笔记模板。 |
| `归档/` | 已不活跃但仍有参考价值的归档内容。 |

每个目录里都有一份 `_说明.md`，忘记用途时可以直接点进去看。
