 # 数据类型
 
### 数值
整数类型：int类型
```python
# 定义一个人的信息，姓名：tom，年龄18岁
name = 'tom'
age = 18
```
小数类型：float类型
```python
# 定义一个超市的收银系统
name = '大白菜'
price = 3.5
```
**如何判断一个变量到底是什么类型**

①使用`type(变量名称)`方法，返回变量的数据类型
```python
name = 'Tom'
age = 18
print(type(name))
print(type(age))
```

②`isinstance(变量名称，数据类型)`，返回True或False
