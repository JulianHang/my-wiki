# Python中的格式化输出
目前为止，我们所有的输出都是直接通过print形式直接打印的，但是实际工作中，我们可能需要对变量的输出进行格式化操作，按照一定格式进行输出。

### 百分号格式化输出
前面有多少个%百分号，后面就应该有多少个变量，而且顺序不能颠倒

```python
# 基础语法
print('字符串%格式' % (变量名称))
print('字符串%格式  %格式  %格式' % (变量名称1, 变量名称2, 变量名称3))
```
```python
# 案例：定义两个变量name = 'itemiam', age = 18, 按照如下格式进行输出，我的名字是iteeima，今年18岁了
name = 'itemiam'
age = 18
print('我的名称是%s, 今年%d岁' % (name, age))

# 案例：今天蔬菜特价了，大白菜只要3.5元/斤
title = '大白菜'
price = 3.5
print('今天蔬菜特价了，%s只要%.2f元/斤' % (title, price))
```

其实除了%f可以设置小数点位数外，%d也可以填充序号
```python
# 案例：定义两个变量 id = '1', name = 'itheima' 按照如下格式进行输出：姓名itheima, 学号000001
id = 1
name = 'itemima'
print('姓名%s, 学号%06d' % (name, id))  # 学号的位置上要填充6位数，不足的用0补
```

### format方法格式化输出
```python
# 基本语法
print('{}字符串{}'.format(变量名称1, 变量名称2))
```

```python
# 案例：定义两个变量，name = '孙悟空' mobile = '188742234324', 按照以下戈斯和进行输出姓名：孙悟空, 联系方式：1890890890
name = '孙悟空'
mobile = '18871231123123'
print("姓名：{}, 联系方式：{}".format(name, mobile))
```

### format方法简写形式格式化输出(推荐)
在Python3.6以后版本，为了简化format输出操作，引入了一个简写形式

```python
name = '孙悟空'
mobile = '18877123123'
print(f'姓名：{name}, 联系方式：{mobile}')
```

### 格式化输出中的转义符号
在字符串中，如果出现了\t和\n，其代表的含义就是两个转义字符

```python
# \t：制表符，一个tab键（4个空格）的距离
# \n：换行符
```

```python
# 案例：
print('*\t')
print('hello\nworld')
```
特别说明：默认情况下，print方法在执行完毕后，都会输出一个\n换行符，如果不想让print方法换行，可以添加一个end参数
```python
print('*', end='')
```
