# Python中的标准输入
到目前为止，我们所有的程序都只能把数据输出给用户，但实际工作中，我们经常获取用户输入的信息。

### input输入方法
在Python中，我们想让Python程序接受用户的输入信息，可以使用input方法
```python
# 基本语法
input()
```
但是往往只有input方法，其意义不大，我们还应该使用一个变量来临时接受用户的输入

```python
# 案例：银行系统中的，输入密码的过程
password = input('请输入你的银行卡密码：')
print(f'您输入的银行卡密码：{password}')
```

记住：所有由input方法获取的数据都是**字符串**类型
