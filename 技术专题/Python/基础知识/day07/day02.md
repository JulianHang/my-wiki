# 引用变量与可变、不可变类型

### 引用变量
在Python中变量的传递基本上都是引用传递。 


#### 如何验证Python中变量的引用关系？

答：可以使用内置方法id(), 其参数就是要显示的变量信息
```python
a = 10
print(id(a))
```

#### 把一个变量赋予给另外一个变量的影响

```python
a = 10
b = a
print(id(a))
print(id(b))
```
当我们把一个变量赋予给另外一个变量时, 其两者指向的内存地址相同, 说明a和b指向了同一块内存空间。


```python
a = 10
b = a

a = 100
print(b)

print(id(a))
print(id(b))
```
总结：不可变数据类型(数值)在赋值以后, 其中一个值的改变不影响另外一个变量, 因为两者指向空间地址不同。

### 可变与非可变数据类型
在Python中有数值(int整型、float浮点类型)、bool类型、字符串类型、元组、列表、字典、集合共有7种数据类型。
在Python中, 我们可以把7种数据类型分为两大类：可变 + 非可变类型。

① 非可变类型
数值、bool类型、字符串类型、元组

② 可变类型
列表、集合、字典

#### 如何判断一个数据类型是可变类型还是非可变类型
可变类型就是在内存中, 其地址可以不变, 但是其内部数据可以改变的一种数据结构。
非可变类型就是在内存中, 当值发生改变时, 其地址也会随着改变(值一旦固定, 就没有办法发生任何改变了)

```python
a = [1, 2, 3]
print(id(a))

a.append(4)
print(id(a))
```

```python
a = 'hello'

print(id(a))

a = 'world'
print(id(a))
```

### 可变类型与非可变类型在函数中的应用

```python
def func(names):
    names.append('赵六')
    print(names)
    pass


list1 = ['张三', '李四', '王五']
func(list1)
print(list1)
```
综上所述：可变类型在函数中, 如果在全局或局部中对可变类型进行增删改操作, 其外部和内部都会受到影响。


```python
def func(num):
    num += 1
    print(num)

a = 10
func(a)
print(a)
```
综上所述：不可变类型在函数中, 局部或全局的改变对外部和内部都没有任何影响。
