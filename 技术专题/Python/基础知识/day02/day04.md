# Python运算符

### 算术运算符
所谓的算数运算符就是我们日常生活中的加减乘除。

| 运算符 | 描述       | 示例                                |
|-----|----------|-----------------------------------|
| /   | 除，带有小数点  | 10/2 输出结果为5                       |
| //  | 整除，不带小数点 | 9//4 输出结果为2                       | 
| %   | 取余           | 9%4 输出结果为 1                       |
| **  | 幂指数         | 2 ** 输出结果为16，即 2的4次方，2* 2 * 2 * 2 |
| {} | 小括号          | 小括号用来提高运算优先级                      

```python
num1 = 10
num2 = 2

print(f'加：{num1 + num2}')
print(f'减：{num1 - num2}')
print(f'乘：{num1 * num2}')
print(f'除：{num1 / num2}')
```
```python
num1 = 20
num2 = 6
num3 = 5

print(f'整除：{num1 // num2}')
print(f'取模：{num1 % num2}')
print(f'幂指数：{num2 ** 3}')
print(f'优先级1：{num1 + num2 * num3}')
print(f'优先级2：{(num1 + num2) * num3}')
```

```python
# 用户输入、数据类型转换以及算术运算符
a = float(input('请输入上底：'))
b = float(input('请输入下底：'))
h = float(input('请输入高：'))

s = (a + b) * h / 2
print(f'梯形的面积：{s}')
```

### 赋值运算符
| 运算符 | 描述       | 示例                                |
|-----|----------|-----------------------------------|
| =   | 赋值       | 将 = 右侧的结果赋值给等号左侧的变量               |
| //  | 整除，不带小数点 | 9//4 输出结果为2                       | 
| %   | 取余       | 9%4 输出结果为 1                       |
| **  | 幂指数      | 2 ** 输出结果为16，即 2的4次方，2* 2 * 2 * 2 |
| {}  | 小括号      | 小括号用来提高运算优先级                      

```python
# 赋值
num1 = 10
n = 5
f = 10.88
s = 'hello world'

# 简写为：多个变量同时进行赋值
n, f, s = 5, 10.88, 'hello world'

# 多个变量赋予相同的值
a = 10
b = 10

# 简写为
a = b = 10

```

### 复合赋值运算符
复合赋值运算符 = 算术运算符 结合 赋值运算符

| 运算符 | 描述      | 示例                                |
|-----|---------|-----------------------------------|
| +=  | 加法赋值运算符 | |
| -=  | 减法赋值运算符 ||
| *=  | 乘法赋值运算符 | |
| %=  | 取余赋值运算符 | |
| **/ | 幂赋值运算符  | |
> 复合赋值运算符的计算顺序 = 先执行算术运算符，执行完毕后，把结果在赋值给左边的变量


### 比较运算符
> 特别注意：当我们使用比较运算符对两个变量进行比较时，其返回一个布尔类型的值。
```python
num1 = 10
num2 = 20
print(num1 > num2) # False
print(num2 > num1) # True
```
