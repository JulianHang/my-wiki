### 基本语法

```python
# if 条件判断：

```

### if...elif...else 多条件判断结构
如果条件1成立，则执行语句段1；
如果条件2成立，则执行语句段2；
...
当所有条件都不成立时，则执行else语句段中的内容
```python
# if 条件判断1：
#     如果此条件为True，则执行这个语句段
# elif 条件判断2：
#     如果此条件为True，则执行这个语句段
# elif ...:
#     ...
# else:
#     如果以上所有条件判断都不满足时，则执行这个语句段

```

```python
# 案例：
# ①中国合法工作年龄为18-60岁，即如果年龄小于18的情况为童工，不合法
# ②如果年龄在18-60岁之间为合法工龄
# ③大于60岁为法定退休年龄

age = int(input("请输入你的年龄："))

if age < 18:
    print(f'童工')
elif 18 <= age <= 60:
    print(f'合法工龄，可以工作')
elif age > 60:
    print(f'退休年龄')
else:
    print(f'错误输入')

```


### if嵌套结构

```python

#     # True，则执行以下语句段
#     if 内层条件判断：

```
