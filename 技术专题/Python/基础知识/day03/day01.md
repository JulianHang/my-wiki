### 判断是否为一个合法三角形
> 需求：输入三角形的3边，如果两边的长度大于第3条边，则代表是一个合法三角形

```python
a = input('请输入第1条边的长度：')
b = input('请输入第2条边的长度：')
c = input('请输入第3条边的长度：')

if (a + b > c) and (a + c > b) and (b + c > a):
    print('是一个合法的三角形')
else:
    print('不是一个合法的三角形')

```

### 求世界杯小组赛的总成绩
> 需求：世界杯案例，世界杯小组赛的比赛规则是我们的球队与其他三支球队进行比赛，然后根据总成绩确定出线资格。小组赛球队实力已知，我们通过一个数字表示。如果我们赢1局得3分，平一局得1分，输一局得0分，最终求球队总成绩。
```python
a = int(input('请输入我们球队的实力：'))
b = int(input('请输入1号球队的实力值：'))
c = int(input('请输入2号球队的实力值：'))
d = int(input('请输入3号球队的实力值：'))

avsb = (a > b) * 3 + a == b
avsc = (a > c) * 3 + a == c
avsd = (a > d) * 3 + a == d

score = avsb + avsc + avsd
print(f'我们球队最终的总成绩：{score}')


```
