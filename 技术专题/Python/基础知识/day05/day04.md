# 元组
村粗多个数据，但是这些数据是不能修改的。定义元组使用小括号，且使用逗号隔开各个数据，数据可以是不同的数据类型。

```python
t1 = (10, 20, 30)
t2 = (10, )
```
> 如果定义的元组只有一个数据，那么这个数据后面也要添加逗号，否则数据类型为唯一的这个数据的数据类型

```python
# 在尾部加了逗号, 表示t2是一个元组
t2 = (10, ) 
# 在尾部没有加逗号的话, 表示t3是一个数字类型, 加了一个括号而已
t3 = (10)
```

```python
tuple1 = (10, 20, 30)
print(tuple1)
print(type(tuple1))

tuple2 = (10,)
print(tuple2)
```

### 元组的操作方法
由于元组中的数据不允许直接修改, 所以其操作方法大部分为查询方法。

元组[索引下标]: 根据索引下标查找元素
index(): 查找某个数据, 如果数据存在返回对应的下标, 否则报错, 语法同列表、字符串的index方法相同
count(): 统计某个数据在当前元组出现的次数
len(): 统计元组中数据的个数

```python
nums = (10, 20, 30)
print(nums[2])

# 查找20
print(nums.index(20))

# 统计
print(nums.count(10))

```
