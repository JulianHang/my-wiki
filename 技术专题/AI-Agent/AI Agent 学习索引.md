# AI Agent 学习索引


## 学习前提
- python基础知识


## 学习目标

把 AI Agent 从"会用工具"学到"能设计系统"。

重点关注：
- Agent 的核心概念和经典范式。
- 工具调用、记忆、检索、上下文工程和协议。
- 主流框架的适用边界。
- AI 编程工具链在真实开发中的落地方式。


## 推荐阅读顺序

1. Hello-Agents


## 读完后要沉淀的笔记

- Agent 和普通 LLM 应用的区别。
- ReAct、Reflection、Plan-and-Solve 的适用场景。
- Memory 和 RAG 的边界。
- MCP 在 Agent 系统里的角色。
- 多智能体是否真的必要，以及何时不要用。
- AI 编程工具链如何服务真实项目，而不是只做演示。
