# Claude HowTo

## 资料入口

- GitHub：https://github.com/luongnv89/claude-howto

## 资料定位

这个仓库更像 Claude Code 的实战学习路线，而不是通用 AI Agent 原理教程。

适合用来学习 AI 编程工具链如何落地，包括命令、记忆、技能、Hook、MCP、子代理、插件和 CLI 自动化。

## 重点内容

- Slash Commands：把重复操作沉淀成命令。
- Memory：让工具记住项目规范和个人偏好。
- Skills：把专业能力封装成可复用能力。
- Hooks：在工具调用前后做自动校验或流程控制。
- MCP：接入 GitHub、数据库等外部系统。
- Subagents：把复杂任务拆给专门角色。
- Plugins：把团队工作流打包分发。
- CLI：用于脚本、批处理和 CI/CD。

## 我的使用方式

把它当作 AI 编程工作流手册。

建议优先看：
1. Slash Commands
2. Memory
3. Skills
4. MCP
5. Subagents
6. CLI

如果后续要搭自己的 Agent 工具链，再深入 Hooks、Plugins 和高级特性。

## 和 Hello-Agents 的关系

- Hello-Agents 负责理解 Agent 系统如何设计。
- Claude HowTo 负责理解 AI 编程工具如何服务真实开发。

两者结合起来，一个偏“系统原理”，一个偏“工程效率”。
