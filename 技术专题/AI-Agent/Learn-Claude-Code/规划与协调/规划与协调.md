# 规划与协调

## TodoWrite
执行任务前，先输出整体计划。

## SubAgent
创建子Agent，单独一个上下文，互相隔离。

## Skills
按需加载相关知识点。

## System Prompt
系统提示词，固定的内容排前面，动态的内容按需加载。

## Error Recovery
错误恢复，对大模型抛出错误分类处理，按照不同策略恢复执行。

### max_tokens
max_token用完了，大模型输出了截断后的内容，解决方案：首次发生时，先升级max_token的值，重试同一请求，此时不将截断后的内容追加到消息中；若在升级max_token后仍然不足，则将截断后的消息追加到消息中，让大模型接着刚才的输出继续说，若连续多次提示max_tokens，则直接退出。

### prompt_too_long
上下文窗口超过限制，先执行reative compact，重试所有压缩策略，压缩后还是超限的话，则直接退出。

### 临时故障
网络抖动、限流（429）、过载（529），解决方案：网络抖动采用重试，有重试次数上限、限流与过载采用指数退避+随机，避免同一时刻大量请求，多次过载的话，可以切换到备用模型上。
