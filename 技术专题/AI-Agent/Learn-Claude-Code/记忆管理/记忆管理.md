# 记忆管理

## Context Compact
当上下文窗口的消息达到一定阈值后会进行上下文压缩。

- tool-result-budget：若所有工具的结果超过阈值，按照工具结果的内容大小倒序排列，优先处理内容过大的工具结果，先将工具结果落盘，在将内存中的工具结果进行截断，保留前2000个字符 + 特定标识 + 完整工具结果落盘路径

- snip-compact：只保留前面N条消息和最后M条消息，中间的消息裁掉

- mic-compact：在snip-compact的基础上继续压缩，先将工具结果落盘，在将内存中的工具结果保留最近N条 + 特定标识 + 完整工具结果落盘路径。
  
- auto-compact（compact-history）：在mic-compact基础上，先将完整消息落盘，接着让LLM按照消息生成摘要，在内存中把摘要替换成现有消息。

- reactive_compact：当模型API因为提示词太长而调用失败后执行，在auto-compact的基础上先将消息落盘，保留内存中的最近N条消息，将之前的消息进行摘要提取，最后在重试模型调用。

## Memory
对对话历史进行持久化，以便后续对话可以提供给LLM进行参考。
