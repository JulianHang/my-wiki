# 工具与执行

## Agent Loop

用户向大模型发出问题，大模型回答后，结合大模型回答的内容补充新的指令进行下一轮提问，直到大模型认为"无需继续"或者达到最大循环次数即可结束。

## Tool Use

定义多个工具及工具注册（工具执行的结果需要在告知到LLM）

## Permission

工具执行前先做权限判断，权限有：
- 阻止：用户明确拒绝执行的命令列表
- 询问：规则匹配，如命中了规则则询问用户"允许"/"拒绝"，若未命中则允许直接执行

## hooks
hook在工具执行前后注入扩展逻辑


## 值得注意的是
```python
results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": output,
            })
```
这块报文需要放入在下一轮提问的环节中，实际上是在告诉LLM，你前面说的工具我执行了，LLM会告诉你接下来要做什么。
