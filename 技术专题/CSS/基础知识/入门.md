## 书写规则

选择器 {属性名: 属性值;}

```css
p {
    color: red;
}
```

内部样式表
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        /*里面的代码是css*/
        p {
            color: red;
            
            
        }

<body>
    <p>我是个屁</p>
</body>
```

## 选择器


### 标签选择器
使用标签名作为选择器，选中同名标签设置相同的样式


### 类选择器
查找标签，差异化设置标签的显示效果

步骤：
- 定义类选择器：.类名
- 使用类选择器：标签添加 class = "类名"
  
注意：
- 类名自定义，不要用纯数字或中文，尽量用英文命名
- 一个类选择器可以供多个标签使用
- 一个标签可以使用多个类名，类名之间用空格隔开


### id选择器
查找标签，差异化设置标签的显示效果，id选择器一般配合js使用，很多用来设置css样式

步骤：
- 定义id选择器：id名
- 使用id选择器：标签添加id = "id名"


规则：同一个id选择器在一个页面只能使用一次

### 通配符选择器
查找页面锁于标签，设置相同样式

通配符选择器：*，不需要调用，浏览器自动查找页面所有标签，设置相同的样式

### 复合选择器
由两个或多个基础选择器，通过不同的方式组合而成。

#### 后代选择器
选中某元素的后代元素。写法：父选择器 子选择器{CSS属性}，父子选择器之间用空格隔开。

```html
<style>
    div span {
        color: red;
    }
</style>

<span>标签</span>
<div>
    <!-- 被选中 -->
    <span>这是div的儿子</div>
</div>
```
后代选择器执行代码的时候，先执行孩子，后执行父亲，先找li 后找ul，我们找刘德华，先确定刘德华（li），然后确定刘德华在淄博（ul）吃烧烤

#### 子代选择器
选中某元素的子代元素（最近的子级）。写法：父选择器 > 子选择器{CSS属性}，父子选择器之间用 > 隔开。

```html
<style>
    div>span {
        color: red;
    }
</style>

<div>
    <!-- 被选中 -->
    <span>我是儿子</span>
    <p>
        <span>我是孙子</span>
    </p>
</div>
```

#### 并集选择器
选中多组标签设置相同样式

```html
<style>
    div, span, p {
        color: red;
    }
</style>

<!-- 被选中 -->
<div>
    我是div
</div>
<!-- 被选中 -->
<span>我是span</span>
<!-- 被选中 -->
<p>我是p</p>
```

#### 交集选择器
选中同时满足多个条件的元素

```html
<style>
    div.red {
        color: red;
    }
</style>

<!-- 被选中 -->
<div class = "red">我是div</div>
<!-- 被选中 -->
<div class = "red">我是div</div>
<div >我是div</div>
<span>我是span</span>
<span>我是span1</span>
```

#### 伪类选择器
伪类表示元素状态，选中元素的某个状态设置样式。写法：选择器:hover {CSS属性}


### 结构伪类选择器
根据元素的结构关系查找元素

- E:first-child：查找第一个E元素
- E:last-child：查找最后一个E元素
- E:nth-child(N)：查找第N个E元素（第一个元素N值为1）



### 伪元素选择器
创建虚拟元素（伪元素），用来摆放装饰性的内容

- E::before：在E元素里面最前面添加一个伪元素
- E::after：在E元素里面最后面添加一个伪元素

注意点:
- 必须设置content: "" 属性，用来设置伪元素的内容，如果没有内容，则引号留空即可
- 伪元素默认是行内显示模式
- 权重和标签选择器相同，都是1


## 样式

- font-size：文字尺寸，pc端网页最常用的单位px

- font-weight：字体粗细。400 等价于 normal，700等价于bold（加粗）

- font-style：字体倾斜。
  - 正常：normal
  - 倾斜：italic
  
- line-height：行高，设置多行文本的间距
  - 数字 + px
  - 数字（当前标签font-size属性值的倍数）

- font 复合属性：

font: 是否倾斜  是否加粗  字号/行高 字体；严格按照顺序来写，有2个地方必须写，一个字号，一个字体
```css
div {
    /*是否倾斜*/
    font-style: italic;
    /*加粗*/
    font-weight: 700;
    /*字号*/
    font-size: 18px;
    /*行高*/
    line-height: 30px;
    /*字体*/
    font-family: 'Courier New', Courier, monospace;
}

/*复合属性*/
div {
    font: italic 700 18px/30px 'Courier New', Courier, monospace;
}
```


- text-indent：文字缩进
  - 数字 + px
  - 数字 + em（推荐：1em = 当前标签的字号大小），其中em是相对单位，1em就是当前元素1个文字的大小

- text-align：控制内容水平对齐方式（行内元素），要设置给内容的父级，其父级要独占一行，块级元素
  - left：左对齐
  - center：居中对齐
  - right：右对齐


- text-decoration：文本修饰线
  - none：无
  - underline：下划线
  - line-through：删除线
  - overline：上划线

- color：文字颜色
  - 颜色关键字：red、green、blue
  - rgb表示法：rgb(r,g,b)
  - rgba表示法：rgba(r,g,b,a)，alpha 透明度 0 - 1
  - 十六进制表示法：#RRGGBB

- background-image：设置背景图

- background-repeat：背景图平铺方式
  - no-repeat：不平铺
  - repeat：平铺（默认）
  - repeat-x：水平方向平铺
  - repeat-y：垂直方向平铺

- background-position：设置背景图的位置，水平方向位置和垂直方向位置
  - 关键词：left、right、center、top、bottom，可以颠倒取值顺序，可以只写一个关键字，另外一个方向默认为居中，水平方向的关键词是left/right/center，垂直方向的关键词是top/center/bottom
  - 坐标：数字 + px，正负都可以，只写一个值表示水平方向，垂直方向居中，有严格的顺序
  
```html
<style>
    div {
        background-position: center center;
    }
</style>
```

- background-size：设置背景图缩放，宽度  高度
  - 关键字：
    - cover：等比例缩放背景图片以完全覆盖背景区，可能背景图片部分看不见，简单理解就是图片要铺满整个盒子
    - contain：等比例缩放背景图片以完全装入背景区，可能背景区部分空白，简单理解就是图片要展示完整
  - 百分比：根据盒子尺寸计算图片大小
  - 数字 + 单位，例如px
```html
<style>
    div {
        width
        background-si: center center;
    }
</style>
```

- background-attachment：设置背景图固定
  - scroll：背景图是滚动的，默认值
  - fixed：背景图是固定的

- background：设置背景复合属性 
  - 背景色 背景图 背景图平铺方式 背景图位置/背景图缩放 背景图固定；空格隔开各个属性值，不区分顺序，其中背景图位置/背景图缩放是一组，如果只出现齐总一个的话可以不用加斜杠，若是出现斜杠的话，两者都要出现，且不能分开写



## 层叠性
特点：
- 相同的属性会覆盖：后面的CSS属性覆盖前面的CSS属性
- 不同的属性会叠加：不同的CSS属性都生效

注意：选择器类型相同则遵循层叠性，否则按选择器优先级来判断。

规则：选择器优先级高的样式生效。通配符选择器 < 标签选择器 <  类选择器 < id选择器 < 行内样式 < !important（选中标签的范围越大，优先级越低）


```css
div {
    color: green!important
}
```

复合选择器累加权重，以下是各自的权重
- 继承/通配符：0
- 标签选择器：1
- 类/伪类选择器：10
- id选择器：100
- 行内样式：1000
- !important：无穷大

```html

<style>
    /* 标签选择器权重是1 */
    li {
        color: red;
    }
    /* 权重是 1 + 1 = 2 */
    ul li {
        color: green;

    }
    /* 权重是10 */
    .blue {
        color: blue;
    }
    /* 交集选择器，权重是 1 + 10 = 11 */
    li.blue {
        color: pink;
    }

</style>


<body>
    <ul>
        <li class = "blue">我是文字</li>
    </ul>

</body>
```


## 属性继承
CSS 中，文字和排版相关属性通常可以继承，跟盒子相关的不会继承。


## 显示模式

- 块级元素
  - 独占一行
  - 宽度默认是父级的100%
  - 添加宽高属性生效

- 行内元素
  - 一行可以显示多个
  - 设置宽高属性不生效
  - 宽高尺寸由内容撑开，根据自己的内容撑开

- 行内块元素，典型的元素是 img、input、td，默认情况下宽度不会跟父亲一样
  - 一行可以显示多个
  - 设置宽高属性生效
  - 宽高尺寸也可以由内容撑开


## 转换显示模式
属性名：display

属性值：
- 块级：block
- 行内块：inline-block
- 行内：inline


## 盒子模型

### 边框线
属性名：border（bd）
属性值：边框线粗细 线条样式 颜色（不区分顺序）

常用线条样式：
- solid：实线
- dashed：虚线
- dotted：点线

### 内边距
作用：设置内容与盒子边缘之间的距离
属性名：padding

padding: 10px;              /* 四个方向相同 */
padding: 10px 20px;         /* 上下、左右 */
padding: 10px 20px 30px;    /* 上、左右、下 */
padding: 10px 20px 30px 40px; /* 上、右、下、左 */



### 尺寸计算
盒子尺寸 = 内容尺寸 + border尺寸 + 内边距尺寸

盒子尺寸要固定像素，比如200px，但是加了border和padding的话会增大盒子尺寸，解决办法如下：
- 手动做减法：减掉border/padding的尺寸
- 内减模式：box-sizing: border-box（css3增加的属性，设置完后相当于内容尺寸减少了，等同于手动做减法）

### 外边距
作用：拉开两个盒子之间的距离
属性名：margin
技巧：版心居中-左右margin值为auto（盒子要有宽度，且是块级元素），margin:0 auto

margin-left：auto（盒子靠右）
margin-right：auto（盒子靠左）



## 清除默认样式
清除标签默认的样式，比如：默认的内外边距

```html

<style>
    * {
        margin: 0;
        padding: 0;
    }

    li {
        list-style: none;
    }
</style>
```

## 元素溢出
作用：控制溢出元素的内容的显示方式
属性名：overflow
属性值：
- hidden：溢出隐藏
- scroll：溢出滚动，无论是否溢出，都显示滚动条位置
- auto：溢出滚动，溢出才显示滚动条位置

## 外边距问题-合并现象
场景：垂直排列的兄弟元素，上下margin会合并
现象：取两个margin中的较大值生效

```html

<style>
    .box1 {
        width: 100px;
        height: 100px;
        background-color: pink;
        margin-bottom: 100px;
    }
    .box2 {
        width: 100px;
        height: 100px;
        background-color: blue;
        margin-top: 50px;
    }
</style>

<body>
    <div class="box1">上</div>
    <div class="box2">下</div>
</body>
```

## 外边距塌陷-塌陷问题
场景：父子级的标签，子级添加上外边距会产生塌陷问题
现象：导致父级一起向下移动

```html

<style>
    .father {
            width: 200px;
            height: 200px;
            background-color: pink;
            overflow: hidden;
    }
    .son {
        width: 100px;
        height: 100px;
        background-color: blue;
        margin-top: 50px;
    }
</style>

<body>
    <div class="father">
        <div class="son"></div>
    </div>
</body>
```

解决办法：
- 取消子级margin，父级设置padding
- 父级设置overflow: hidden
- 父级设置 border-top


## 行内元素-内外边距问题
场景：行内元素添加margin和padding，无法改变元素垂直位置
解决办法：给行内元素添加line-height，可以改变垂直位置


```html

<style>
    .box {
        margin: 10px;
        line-height: 10px;
    }
</style>

<body>
    <span class="box">123</span>
</body>
```

## 盒子模型-圆角
作用：设置元素的外边框为圆角
属性名：border-radius
属性值：数字+px/百分比
提示：属性值是圆角半径

技巧：
- 若要设置成圆形，在正方形下border-radius设置成像素的50%
- 若要设置成胶囊装，border-radius设置成高度像素的50%

- 一个值：border-radius:10px; 四个角均为10px
- 两个值：10px 60px; 左上+右下 = 10  右上 + 左下 = 60
- 三个值：10px 40px 80px;  左上 = 10   右上 + 左下 = 40  右下 = 80
- 四个值：左上 右上 右下 左下

## 盒子模型-阴影
作用：给元素设置阴影效果
属性名：box-shadow
属性值：X轴偏移量  Y轴偏移量  模糊半径   扩散半径   颜色  内外阴影

注意：X轴偏移量  Y轴偏移量 必须书写；默认是外阴影，内阴影需要添加inset


```html

<style>
    .box {
        border-radius: 50%;
        box-shadow: 2px 2px 2px 2px black;
    }
</style>

<body>
    <img src="./1.png" alt="" class = "box">
</body>
```
