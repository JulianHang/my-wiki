# CSS入门

## 书写规则

选择器 {属性名: 属性值;}

```css
p {
    color: red;
}
```


## 引入方式

内部样式表
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <style>
        /*里面的代码是css*/
        p {
            color: red;
            
            
        }
    </style>
</head>
<body>
    <p>我是个屁</p>
</body>
</html>
```


行内样式，适用于少量的样式，通常配合js使用
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
    <link rel="stylesheet" href="./my.css">
</head>
<body>
    <button style = "color: red;">按钮</button>
</body>
</html>
```


## 选择器


### 标签选择器
使用标签名作为选择器，选中同名标签设置相同的样式


### 类选择器
查找标签，差异化设置标签的显示效果

步骤：
- 定义类选择器：.类名
- 使用类选择器：标签添加 class = "类名"
  
注意：
- 类名自定义，不要用纯数字或中文，尽量用英文命名
- 一个类选择器可以供多个标签使用
- 一个标签可以使用多个类名，类名之间用空格隔开


### id选择器
查找标签，差异化设置标签的显示效果，id选择器一般配合js使用，很多用来设置css样式

步骤：
- 定义id选择器：id名
- 使用id选择器：标签添加id = "id名"


规则：同一个id选择器在一个页面只能使用一次

### 通配符选择器
查找页面锁于标签，设置相同样式

通配符选择器：*，不需要调用，浏览器自动查找页面所有标签，设置相同的样式

### 复合选择器
由两个或多个基础选择器，通过不同的方式组合而成。

#### 后代选择器
选中某元素的后代元素。写法：父选择器 子选择器{CSS属性}，父子选择器之间用空格隔开。

```html
<style>
    div span {
        color: red;
    }
</style>

<span>标签</span>
<div>
    <!-- 被选中 -->
    <span>这是div的儿子</div>
</div>
```
后代选择器执行代码的时候，先执行孩子，后执行父亲，先找li 后找ul，我们找刘德华，先确定刘德华（li），然后确定刘德华在淄博（ul）吃烧烤

#### 子代选择器
选中某元素的子代元素（最近的子级）。写法：父选择器 > 子选择器{CSS属性}，父子选择器之间用 > 隔开。

```html
<style>
    div>span {
        color: red;
    }
</style>

<div>
    <!-- 被选中 -->
    <span>我是儿子</span>
    <p>
        <span>我是孙子</span>
    </p>
</div>
```

#### 并集选择器
选中多组标签设置相同样式

```html
<style>
    div, span, p {
        color: red;
    }
</style>

<!-- 被选中 -->
<div>
    我是div
</div>
<!-- 被选中 -->
<span>我是span</span>
<!-- 被选中 -->
<p>我是p</p>
```

#### 交集选择器
选中同时满足多个条件的元素

```html
<style>
    div.red {
        color: red;
    }
</style>

<!-- 被选中 -->
<div class = "red">我是div</div>
<!-- 被选中 -->
<div class = "red">我是div</div>
<div >我是div</div>
<span>我是span</span>
<span>我是span1</span>
```

#### 伪类选择器
伪类表示元素状态，选中元素的某个状态设置样式。写法：选择器:hover {CSS属性}


## 样式

- font-size：文字尺寸，pc端网页最常用的单位px

- font-weight：字体粗细。400 等价于 normal，700等价于bold（加粗）

- font-style：字体倾斜。
  - 正常：normal
  - 倾斜：italic
  
- line-heigth：行高，设置多行文本的间距
  - 数字 + px
  - 数字（当前标签font-size属性值的倍数）

- font 复合属性：font: 是否倾斜  是否加粗  字号/行高 字体;

严格按照顺序来写，有2个地方必须写，一个字号，一个字体
```css
div {
    /*是否倾斜*/
    font-style: italic;
    /*加粗*/
    font-weight: 700;
    /*字号*/
    font-size: 18px;
    /*行高*/
    line-height: 30px;
    /*字体*/
    font-family: 'Courier New', Courier, monospace;
}

/*复合属性*/
div {
    font: italic 700 18px/30px 'Courier New', Courier, monospace;
}
```


- text-indent：文字缩进
  - 数字 + px
  - 数字 + em（推荐：1em = 当前标签的字号大小），其中em是相对单位，1em就是当前元素1个文字的大小

- text-align：控制内容水平对齐方式，要设置给内容的父级，其父级要独占一行，块级元素
  - left：左对齐
  - center：居中对齐
  - right：右对齐


- text-decoration：文本修饰线
  - none：无
  - underline：下划线
  - line-through：删除线
  - overline：上划线

- color：文字颜色
  - 颜色关键字：red、green、blue
  - rgb表示法：rgb(r,g,b)
  - rgba表示法：rgba(r,g,b,a)，alpha 透明度 0 - 1
  - 十六进制表示法：#RRGGBB
