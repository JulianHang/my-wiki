# 进阶

## 标准流
标准流也叫文档流，指的是标签在页面中默认的排布规则，例如：块元素独占一行，行内元素可以一行显示多个。

## 浮动
作用：让块元素水平排列
属性：float
属性值:
- left：左对齐
- right：右对齐

特点：
- 浮动后的盒子顶对齐
- 浮动后的盒子具备行内块特点
- 浮动后的盒子脱标，不占用标准流的位置

```html
 <style>
    * {
        margin: 0;
        padding: 0;
        box-sizing: border-box;
    }
    .mi {
        width: 1226px;
        height: 614px;
        /* background-color: pink; */
        margin: 100px auto;
    }
    .left {
        float: left;
        width: 234px;
        height: 614px;
        background-color: skyblue;
        
    }
    .right {
        float: right;
        width: 978px;
        height: 614px;
        background-color: purple;
    }

</style>
<body>
    <div class = "mi">
        <div class="left">左侧</div>
        <div class="right">
            
        </div>
    </div>
</body>

```


## 清除浮动
场景：浮动元素会脱标，如果父级没有高度，子级无法撑开父级高度（父级没有设置宽高），子级设置浮动后，父级会不见了（因为子级浮动了）

解决方式：
方法一：额外标签法
- 在父元素内容的最后添加一个块级元素，设置css属性：clear: both
  
方法二：单伪元素法
```html
<style>
    .clearfix::after {
        content: "";
        display: block;
        clear: both;
    }
</style>
```

方法三：双伪元素法（推荐）
```html
<style>
    .clearfix::before,
    .clearfix::after {
        content: "";
        display: table;
    }
    .clearfix::after {
        clear: both;
    }
</style>
```

方法四：overflow
- 父元素添加css属性 overflow: hidden


## flex布局
设置方式：给父元素设置display: flex，子元素（不包括子子元素）可以自动挤压或拉伸，不管子盒子是块级元素还是行内元素

组成部分：
- 弹性容器（父级）
- 弹性盒子（子级）
- 主轴：默认在水平方向
- 侧轴/交叉轴：默认在垂直方向

### 主轴对齐方式
属性名：justify-content（给弹性容器设置）
属性值：
- flex-start：默认值，弹性盒子从起点开始依次排列
- flex-end：弹性盒子从终点开始依次排列
- center：弹性盒子沿主轴居中排列
- space-between：弹性盒子沿主轴均匀排列，空白间距均分在弹性盒子之间（让第一个元素贴左、最后一个元素贴右，中间剩余空间平均分配。）
- space-around：弹性盒子沿主轴均匀排列，空白间距均分在弹性盒子两侧
- space-evenly：弹性盒子沿主轴均匀排列，弹性盒子与容器之间间距相等

记忆：
两侧没缝隙是 between，缝隙一样大是 evenly，2倍缝隙是 around


### 侧重对齐方式
属性名：align-items（给弹性容器设置）

属性值：
- stretch：弹性盒子沿着侧轴线被拉伸至铺满容器（弹性盒子没有设置侧轴方向尺寸则默认拉伸，就是侧轴方向没有设置高度，拉伸和父级一样高）
- center：弹性盒子沿侧轴居中排列
- flex-start：弹性盒子从起点开始依次排列
- flex-end：弹性盒子从终点开始依次排列

### 弹性盒子换行
弹性盒子可以自动挤压或拉伸，默认情况下，所有弹性盒子都在一行显示。
属性名：flex-wrap
属性值：
- wrap：换行
- nowrap：不换行（默认）

### 行对齐方式
属性名：align-content
属性值：
- flex-start：默认值，弹性盒子从起点开始依次排列
- flex-end：弹性盒子从终点开始依次排列
- center：弹性盒子沿主轴居中排列
- space-between：弹性盒子沿主轴均匀排列，空白间距均分在弹性盒子之间（让第一个元素贴左、最后一个元素贴右，中间剩余空间平均分配。）
- space-around：弹性盒子沿主轴均匀排列，空白间距均分在弹性盒子两侧
- space-evenly：弹性盒子沿主轴均匀排列，弹性盒子与容器之间间距相等

### align-self 单独控制某个盒子
样式加在子级上


### 修改主轴方向
主轴默认在水平方向，侧轴默认在垂直方向
属性名：flex-direction
属性值：
- row：水平方向，从左到右（默认）
- column：垂直方向，从上到下
- row-reverse：水平方向，从右到左
- column-reverse：垂直方向，从下到上

### 弹性伸缩比
作用：控制弹性盒子的主轴方向的尺寸（设置到子级上）
属性名：flex
属性值：整数数字，表示占用父级剩余尺寸的份数

## 定位
作用：灵活的改变盒子在网页中的位置
实现
- 定位模式：position
- 边偏移：设置盒子的位置
  - left、right、top、bottom

### 相对定位
postion：relative
特点：
- 不脱标，占用自己原来位置
- 显示模式特点保持不变，行内元素还是行内元素，块级还是块级
- 设置边偏移则相对自己原来位置移动

```html
<style>
    .box {
            position: relative;
            /* 不会影响其他盒子 */
            /* left: 100px;
            top: 100px; */
            width: 300px;
            height: 100px;
            /* 会影响其他盒子 */
            /* margin-top: 100px; */
            background: pink;
        }
        .b {
            height: 200px;
            background: black;
        }
</style>

<div class="box"></div>
<div class="b"></div>

```


### 绝对定位
position：absolute
使用场景：子级绝对定位，父级相对定位（子绝父相）
特点：
- 脱表，不占位
- 显示模式具备行内块特点
- 设置边偏移则相对最近的已经定位的祖先元素改变位置
- 如果祖先元素都未定位，则相对浏览器可视区改变位置

```html
 <style>
    .father {
        position: absolute;
        width: 500px;
        height: 500px;
        background-color: pink;
        margin: 200px;
    }

    .son {
        position: absolute;
        bottom: 0;
        right: 0;
        width: 200px;
        height: 200px;
        background-color: purple;
    }
</style>

<div class="father">
    <div class="son"></div>
</div>
```

### 定位居中
transform: translate(-50%, -50%)

### 固定定位
position: fixed
场景：元素的位置在网页滚动时不会改变位置
特点：
- 脱标，不占位
- 显示默认具备行内块特点
- 设置边偏移相对浏览器窗口改变位置

通常情况下，固定定位的盒子要给宽度的。

### 堆叠层级 z-index
默认效果：按照标签书写顺序，后来者居上
作用：设置定位元素的层级顺序，改变定位元素的显示顺序
属性名：z-index
属性值：整数数字（默认值为0，取值越大，层级越高）


### 定位-总结
|定位模式| 属性值 | 是否脱标 | 显示模式 | 参照物 |
|相对定位| relative | 否 | 保持标签原有显示模式 | 自己原来位置 |
| 绝对定位 | absolute | 是 | 行内块特点 | 已经定位的祖先元素或浏览器可视区|
| 固定定位 | fixed | 是 | 行内块特点 | 浏览器窗口| 


### 粘性定位sticky
粘性定位可以被认为是相对定位和固定定位的混合。元素在跨越特定阈值前为相对定位，之后为固定定位。
注意：必须指定top、right、bottom、left四个值中的其中一个

## 垂直对齐方式
属性名：vertical-align
属性值：
- baseline：基线对齐（默认）
- top：顶部对齐
- middle：居中对齐
- bottom：底部对齐

vertical-align: baseline：让元素的基线与所在行的文字基线对齐。基线可以近似理解为大多数字母"坐"着的那条线。图片默认按 baseline 对齐：图片底边靠近文字基线，但基线下方还要留出 g、p 等字母下伸部分的空间，所以图片下面可能看到一小段空隙。

vertical-align: bottom：让元素的底边与所在行的行盒底边对齐

通常情况下是与行内块元素搭配使用，接着在使用margin属性来细微调整。


## 过渡transition
作用：可以为一个元素在不同状态之间切换的时候添加过渡效果
属性名：transition
属性值：过渡的属性 花费的时间（s）
```html
 <style>
    .box {
        width: 200px;
        height: 200px;
        background-color: pink;
        transition: height .2s, width .3s;
        /* ease 的效果是开始较慢、中间较快、结束再变慢，也是 CSS 过渡的默认速度曲线 */
        /* transition: .2s ease; */
    }

    .box:hover {
        height: 300px;
        width: 300px;
    }
</style>

<div class="box"></div>

```

## 透明度opacity
作用：设置整个元素的透明度（包括背景和内容），文字和盒子会一起半透明
属性名：opacity
属性值:
- 0：完全透明
- 1：不透明
- 0-1之间小数：半透明

跟background-color相比的话，bgc只是让盒子透明，里面的内容不会透明。


## 显示隐藏

## css变量
自定义属性（有时候也被称作css变量），声明一个自定义属性，属性名需要以两个减号（--）开始，属性值则可以是任何有效的css值

```html
<style>
:root {
    --color: pink
}
</style>

```
通常最佳实践是定义在根伪类 :root 下，这样子就可以在HTML文档的任何地方访问到。使用一个自定义属性，需要使用var() 来使用

```html
<style>
:root {
    --myColor: pink
}

.box {
    color: var(--myColor)
}
</style>

```


## 平面转换
使用transform属性实现元素的位移、旋转、缩放等效果。
属性名：transform
属性值：
- translate（水平移动距离, 垂直移动距离）
- rotate（角度），旋转效果
- transform-origin改变转换原点
  - 默认原点是盒子中心点
  - 原点水平位置、原点垂直位置
- scale（x轴缩放倍数, y轴缩放倍数）
  - scale值大于1表示放大，小于1表示缩小

## 物理分辨率和逻辑分辨率
物理分辨率：仍然是 1920 × 1080，不会改变。
系统显示缩放：150% 后，文字和界面会变大，可用显示空间相当于缩小

## 百分比布局

## 等比适配
rem单位，是相对单位，相对于HTML标签的字号计算结果，1rem = 1HTML字号大小，比如HTML字号大小是 font-size: 16，那么2rem 就是  2 * 16 = 32。目前rem布局方案中，将网页等分成10份，HTML标签的字号为视口宽度的1/10，这个是10份是约定俗成的，也可以是其他数字。

vw：相当单位，相对于视口宽度的1%，1vw = 1%
vh：相当单位，相对于视口高度的1%，1vh = 1%

vw使用起来比rem更简单，因为vw本身就是参照于视口的

## 媒体查询
媒体查询能够检测视口的宽度，然后编写差异化的CSS样式

@medis (媒体特性) {
    选择器 {
        css属性
    }
}

```html
<style>

@medis (width: 320px) {
    html {
        font-size: 16px;
    }
}


/* 最大宽度 */
@media (max-width: 768px) {
    html {
        background-color: red;
    }
}


/* 最小宽度 */
@media (min-width: 768px) {
    html {
        background-color: blue;
    }
}
</style>

```
