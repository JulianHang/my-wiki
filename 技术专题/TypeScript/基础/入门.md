# 入门

## ts 是什么

ts 是具有类型语法的 js，是一门强类型的编程语言。ts 编写的代码是无法直接在 js 引擎（浏览器/node）中运行的，最终还需要经过编辑变成 js 代码才可以正常运行。

好处：

1. 静态类型检查
2. 良好的代码提示

```ts
let count: number = 100
```

## 安装编译环境与验证

执行命令：npm i -g typescript
查看是否安装成功：tsc -v
执行 ts 脚本会生成一个 js 文件出来：tsc xx.ts

## 搭建工程化下的自动编译环境

基于工程化的 ts 开发模式（webpack/vite），ts 的编译环境已经内置了，无需手动安装配置，通过以下命令即可创建一个最基础的自动化的 ts 编译环境

```javascript
npm create vite@latest ts-pro -- --template vanilla-ts
```

## 常用类型注解

- 简单类型：number、string、boolean、null、undefined
- 复杂类型：数组、函数

```ts
// 数组类型注解
let arr1: number[] = [1, 2, 3]
// 泛型类型
let arr2: Array<number> = [3, 4, 5]

// 函数
function a(a: number, b: number = 1): number {
  return a + b
}

console.log(a(1))

// 分开注解
let b = (a: number, b: number = 1): number => {
  return a + b
}

console.log(b(2))

// 整体注解
type ItemType = (a: number, b?: number) => number
const c: ItemType = (a, b = 1) => {
  return a + b
}
console.log(c(3))
```

- 其他：联合类型、类型别名、接口、字面量类型、泛型、枚举、void、any 等

```ts
// 联合类型
let arr3: (string | number)[] = ['1', 2, 3]

// 接口
interface Person {
  name: string
  age: number
}

const p: Person = {
  name: 's',
  age: 10
}

console.log(p)

// 字面量
type Gender = '男' | '女'

let sex: Gender = '男'
console.log(sex)
```

## 类型别名

通过 type 关键字给写起来复杂的类型起一个其他的名字，用来简化和复用，命名规范采用大驼峰

```ts
let arr3 = (string | number)[] = ['1', 2]

// 类型别名
type ItemTpye = (string | number)[]
let arr4:ItemType = ['3', 4]

// 对象类型
type Person = {
  name?: string
  age: number
}

const p: Person = {
  age: 10
}


// 继承
type GoodsType = {
  id: string,
  price: number
}

type DisGoodsType = GoodsType & {
  disPrice: number
}

let goods: DisGoodsType = {
  id: '1',
  price: 10,
  disPrice: 100
}

// 案例
type data = {
  title: string,
  content: string
}

type response = {
  code: number,
  msg: string,
  data: data
}

let ex: response = {
  code: 200,
  msg: 'success',
  data : {
    title: 's',
    content: ''
  }
}

console.log(ex);


```

## 可选参数

可选参数表示当前参数可传可不传，一旦传递实参必须保证参数类型正确，它必须在所有参数的末尾

```ts
function d(age: number, sex?: string): void {
  console.log(age, sex)
}

console.log(d(1))
```

## 接口的继承

```ts
interface GoodsType {
  id: string
  price: number
}

interface DisGoodsType extends GoodsType {
  disPrice: number
}

let goods: DisGoodsType = {
  id: '1',
  price: 10,
  disPrice: 100
}

console.log(goods)
```

## interface 和 type 的对比

相同点：

- 都能描述对象类型
- 都能实现继承，interface 使用 extends，tpye 配置交车类型&

不同点：

- type 除了能描述对象外，还可以用来描述自定义其他类型
- 同名的 interface 会合并（定义多个相同 interface，属性会做合并），同名 type 会报错

```ts
// 不会做合并，name和age属性都要设置值
interface Item {
  name: string
}

interface Item {
  age: number
}

let item: Item = {
  name: '',
  age: 1
}

console.log(item)
```

## any 类型

变量被注解为 any 类型之后，ts 会忽略类型检查，错误的类型赋值不会报错，也不会有任何提示。

## 类型断言

有些时候开发者比 ts 本身更清楚当前的类型是什么，可以使用断言（as）让类型更加精确和具体

```ts
const link = document.getElementById('link')
// link.href

const link2 = document.getElementById('link') as HTMLAnchorElement
link2.href
```

类型断言只能够欺骗 ts 编译器，无法避免运行时的错误，滥用类型断言可能会导致运行时错误

## 泛型

是指在定义接口、函数等类型的时候，不预先指定具体的类型，而是在使用的时候在指定类型的一种特性

### 泛型接口

在接口类型的名称后面使用<T>即可声明一个泛型参数，接口里的其他成员都能使用该参数的类型

```ts
interface ResData<T> {}
```

```ts
// 定义泛型
interface ResData<T> {
  code: number
  msg: string
  data: T
}

interface User {
  name: string
  age: number
}

interface Goods {
  id: number
  goodsName: string
}

let user: ResData<User> = {
  code: 200,
  msg: 'success',
  data: {
    name: 'jack',
    age: 18
  }
}

let goods: ResData<Goods> = {
  code: 200,
  msg: 'success',
  data: {
    id: 1,
    goodsName: '衬衫'
  }
}
```

### 泛型别名

type ResData<T> = {}

### 泛型函数

```ts
function fn<T>() {}
```

```ts
function createArray<T>(length: number, value: T): T[] {
  let result: T[] = []
  for (let index = 0; index < length; index++) {
    result[index] = value
  }
  return result
}

createArray<number>(10, 3)
createArray<string>(10, '1')
```

### 泛型约束

有时候泛型函数的内部需要访问一些特定类型的数据才有的属性，此时会有类型错误，需要通过泛型约束解决

```ts
interface LengthObj {
  length: number
}
function logLen<T extends LengthObj>(obj: T) {
  console.log(obj.length)
}

logLen({ length: 10 })
```
