#### 组件化开发
组件化：一个页面可以拆分成一个个组件，每个组件有着自己独立的结构、样式、行为
好处：便于维护、复用
组件分类：普通组件、根组件

#### 普通组件的注册
1. 局部注册：只能在注册的组件中使用
   1. 创建.vue文件
   2. 在使用的组件内导入并注册

```javascript
/**
 * 1. 导入
 * 2. 注册组件-注册成html标签（这样标签就代表组件了）
 * 3. 页面中使用 <HmHeader></HmHeader>
 */
import HmHeader from './components/HmHeader.vue'
import HmMain from './components/HmMain.vue'
import HmFooter from './components/HmFooter.vue'

export default {
  
  // 注册组件
  components: {
    // 标签名: 导入的变量名
    HmHeader: HmHeader,
    HmMain: HmMain,
    HmFooter: HmFooter

  }
}
```

2. 全局注册，所有组件内都能使用
main.js
```javascript
// 全局注册组件（注册后，可以在任意组件中使用）
// 1.导入
import HmButton from './components/HmButton.vue'
// 2.全局注册组件
Vue.component('HmButton', HmButton)

```

#### scoped原理
1. 当前组件内标签都被添加data-v-hash值的属性
2. css选择器都被添加[data-v-hash值]的属性选择器
最终效果：必须是当前组件的元素，才会有这个自定义属性，才会被这个样式作用到

#### 自定义指令

##### 全局自定义指令
main.js
```javascript
Vue.directive('指令名称', {
    bind(ele, obj) {}, // 只执行一次，DOM渲染之前执行，里面可以进行样式操作
    inserted(ele, obj) {}, // 只执行一次，DOM渲染之后执行，里面可以进行行为操作
    update(ele, obj) {}, // 数据更新后执行 
    componentUpdated(ele, obj) {}, // 父子组件都更新后执行
    unbind(ele, obj) {} // 指令解绑的时候执行
})
```

##### 局部自定义指令
某个组件中
```javascript
export default {
    directive: {
        '指令名称': {
            bind(ele, obj) {}, // 只执行一次，DOM渲染之前执行，里面可以进行样式操作
            inserted(ele, obj) {}, // 只执行一次，DOM渲染之后执行，里面可以进行行为操作
            update(ele, obj) {}, // 数据更新后执行 
            componentUpdated(ele, obj) {}, // 父子组件都更新后执行
            unbind(ele, obj) {} // 指令解绑的时候执行
        }
    }
}
```

### 路由

#### vue-route安装和基础配置
1. 安装vue-router包
npm i vue-router@3.5.2

2. 创建路由模块（src/router/index.js）
```javascript
// 导入所需模块
import Vue from 'vue'
import VueRouter from 'vue-router'

// 调用user函数，将VueRouter安装为vue插件
Vue.use(VueRouter)

// 配置路由规则
const  routes = []

// 创建路由的实例对象
const router = new VueRouter({
    // 路由的配置
    routes
})

// 导出路由的实例对象
export default router

```

3. 创建并挂载路由模块（main.js）
```javascript
import Vue from 'vue'
import App from './App.vue'
// 导入路由模块
import router from '@/router'

Vue.config.productionTip = false

new Vue({
  render: h => h(App),
  // 挂载路由模块
  router
}).$mount('#app')

```
以上便是使用vue-router的基础配置。浏览器访问localhost:8080，如果路径自动添加了#，说明配置成功


#### 配置路由规则
1. 配置路由规则，router/index.js中
2. 设置路由出口（<router-view>），在哪里展示组件，在哪里放它
3. 设置超链接（<router-link to='/discover'>发现音乐</router-link>）

组件变化的过程：点击超链接-地址栏改变-匹配路由规则地址-在出口处展示对应的组件

#### 嵌套路由
```javascript
// 配置路由规则
const  routes = [
    // 直接写到这个数组的路由规则，级别最大，叫做一级路由
    // 一级路由组件，只能写在APP.vue中
    {path: '/discover', component: DisCover, children: [
        // 二级路由的path，可以不写/
        // 二级路由的访问地址会和一级路由拼接，比如/discover/tuijian
        {path: 'tuijian', component: Recommend},
        {path: 'toplist', component: TopList},
        {path: 'artlist', component: ArtList},
    ]},
    {path: '/mymusic', component: MyMusic},

    {path: '/follow', component: Follow}
]
```
#### 路由传参
1. xxx/xxx?id=3&name=x：查询参数传参
- 超链接挂好合适的参数
- 跳转后，组件中使用 $router.query.参数名 获取值

2. xxx/xxx/3/汪苏泷：动态路由传参
- 超链接挂好合适的参数
- 路由规则改为{path: '/xxx/:id?', component: x}
- 跳转后，组件中使用 $router.params.id 获取值

### 插槽
1. 在封装组件的时候，将可变的结构设计为插槽
2. 使用上述组件时，可以按需为插槽提供自定义的结构，以达到复用组件

子组件：
使用<slot></slot>标签占位，表示这里要放一些内容，相当于在这里挖了一个坑位，准备放内容

父组件：
使用子组件的时候，在标签中间，为插槽（前面的坑位）提供要展示的内容


#### 具名插槽
<slot name="title"></slot>

```html
<template>
  <div>
    <MyDialog>
        <!-- 可以简写成#:title -->
      <template v-slot:title>
          <h3>温馨提示</h3>
      </template>

    </MyDialog>
  </div>
</template>

```


#### 作用域插槽
子级像父级传递参数

```javascript
// 父组件
<template #default="obj">
    <p>你确定要删除啊？{{ obj.username }}</p>
</template>

<template #default="{username}">
    <p>你确定要删除啊？{{ username }}</p>
</template>


// 子组件
<slot :username="xx"></slot>
```
