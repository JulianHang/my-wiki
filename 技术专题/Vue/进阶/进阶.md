# 进阶

### 工程化

#### 安装vue脚手架
1. npm i -g @vue/cli：安装相关包
2. vue create 项目名称：创建vue项目
3. npm run serve：启动项目

#### 组件命名：多词格式，具体来说三种写法
1. 小驼峰：abcDef.vue
2. 大驼峰：AbcDef.vue
3. 中横线：abc-def.vue

补充：如果文件名不是多次格式，可以在js代码中，指定name，name是多词格式也可以

template只能有一个根元素


#### 数据写法
```vue

    data() {
        return {
            count: 100
        }
    },
    methods: {
        
    }

```

一个组件的data选项必须是一个函数，保证每个组件实例，维护独立的一份数据对象。

如果要使用less，两个步骤
1. lang = less

#### 组件化开发
组件化：一个页面可以拆分成一个个组件，每个组件有着自己独立的结构、样式、行为
好处：便于维护、复用
组件分类：普通组件、根组件

#### 普通组件的注册
1. 局部注册：只能在注册的组件中使用
   1. 创建.vue文件
   2. 在使用的组件内导入并注册

```vue
/**
 * 1. 导入
 * 2. 注册组件-注册成html标签（这样标签就代表组件了）
 * 3. 页面中使用 <HmHeader></HmHeader>
 */
import HmHeader from './components/HmHeader.vue'
import HmMain from './components/HmMain.vue'
import HmFooter from './components/HmFooter.vue'

export default {
  
  // 注册组件
  components: {
    // 标签名: 导入的变量名
    HmHeader: HmHeader,
    HmMain: HmMain,
    HmFooter: HmFooter

  }
}
```

2. 全局注册，所有组件内都能使用
main.js
```vue
// 全局注册组件（注册后，可以在任意组件中使用）
// 1.导入
import HmButton from './components/HmButton.vue'
// 2.全局注册组件
Vue.component('HmButton', HmButton)

```

#### scoped原理
1. 当前组件内标签都被添加data-v-hash值的属性
2. css选择器都被添加[data-v-hash值]的属性选择器
最终效果：必须是当前组件的元素，才会有这个自定义属性，才会被这个样式作用到

#### 组件通信
组件与组件之间的数据传递，组件的数据是独立的，无法直接访问其他组件的数据。

#### 自定义指令

##### 全局自定义指令
main.js
```vue
Vue.directive('指令名称', {
    bind(ele, obj) {}, // 只执行一次，DOM渲染之前执行，里面可以进行样式操作
    inserted(ele, obj) {}, // 只执行一次，DOM渲染之后执行，里面可以进行行为操作
    update(ele, obj) {}, // 数据更新后执行 
    componentUpdated(ele, obj) {}, // 父子组件都更新后执行
    unbind(ele, obj) {} // 指令解绑的时候执行
})
```

##### 局部自定义指令
某个组件中
```vue
export default {
    directive: {
        '指令名称': {
            bind(ele, obj) {}, // 只执行一次，DOM渲染之前执行，里面可以进行样式操作
            inserted(ele, obj) {}, // 只执行一次，DOM渲染之后执行，里面可以进行行为操作
            update(ele, obj) {}, // 数据更新后执行 
            componentUpdated(ele, obj) {}, // 父子组件都更新后执行
            unbind(ele, obj) {} // 指令解绑的时候执行
        }
    }
}
```

### 路由

#### vue-route安装和基础配置
1. 安装vue-router包
npm i vue-router@3.5.2

2. 创建路由模块（src/router/index.js）
```vue
// 导入所需模块
import Vue from 'vue'
import VueRouter from 'vue-router'

// 调用user函数，将VueRouter安装为vue插件
Vue.use(VueRouter)

// 配置路由规则
const  routes = []

// 创建路由的实例对象
const router = new VueRouter({
    // 路由的配置
    routes
})

// 导出路由的实例对象
export default router

```

3. 创建并挂载路由模块（main.js）
```vue
import Vue from 'vue'
import App from './App.vue'
// 导入路由模块
import router from '@/router'

Vue.config.productionTip = false

new Vue({
  render: h => h(App),
  // 挂载路由模块
  router
}).$mount('#app')

```
以上便是使用vue-router的基础配置。浏览器访问localhost:8080，如果路径自动添加了#，说明配置成功
