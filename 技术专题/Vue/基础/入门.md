# 入门

## Vue2

#### 插值表达式{{ }}

插值表达式是一种 Vue 的模板语法

- 使用的数据必须存在
- 支持的是表达式，而非语句，比如 if、for
- 不能在标签属性中使用{{}}插值

```vue
<template>
  <div id="app">
    {{ uname }}
  </div>
</template>

<script>
data: {
  uname: 'lao'
}
</script>
```

### 响应式

数据变化，视图自动更新。数据的值会绑定到 Vue 对象上

### vue 指令

vue 会根据不同的指令，针对标签实现不同的功能，带有 v-前缀的特殊标签属性

#### v-html

类似于 innerHTML，如果值中有包含标签的话，也可以正常解析

```vue
<template>
  <div v-html="str">这是一个div</div>
</template>

<script>
export default {
  data() {
    return {
      str: '你是一个<strong>优秀</strong>的boy'
    }
  }
}
</script>
```

#### v-show 和 v-if

v-show

1. 作用：控制元素显示隐藏
2. 语法：v-show = "表达式" 表达式值 true 显示，false 隐藏
3. 切换 display: none 控制显示隐藏
4. 频繁切换显示隐藏的场景

v-if

1. 作用：控制元素显示隐藏
2. 语法：v-if = "表达式" 表达式值 true 显示，false 隐藏
3. 原理：基于条件判断，是否创建或移除元素节点
4. 要么显示、要么隐藏，不频繁切换的场景

#### v-on

作用：注册事件 = 添加监听 + 提供处理逻辑
语法：

- v-on:事件名 = "内联语句"
- v-on:事件名 = "methods 中的函数名"

简写：@事件名

注意：methods 函数内的 this 指向 vue 实例

#### v-bind

作用：动态的设置 html 的标签属性，比如 src、url、title
语法：v-bind:属性名="表达式"

简写：:src = "url"

#### v-for

作用：基于数据循环，多次渲染整个元素
语法：v-for = "(item, index) in 数组"

#### v-model

作用：给表单元素使用，双向数据绑定
数据变化 -> 视图自动更新
视图变化 -> 数据自动更新
语法：v-model=""

### 指令修饰符

通过.指明一些指令后缀，不同后缀封装了不同的处理操作

1. 按键修饰符
   1. @keyup.enter: 键盘回车监听
2. v-model 修饰符
   1. v-model.trim: 去除首尾空格
3. @事件名.stop → 阻止冒泡
4. @事件名.prevent → 阻止默认行为

2. 数组

### computed 计算属性

基于现有的数据，计算出来的新属性。依赖旧的数据变化，自动重新计算。
语法：

- 声明在 computed 配置项中，一个计算属性对应一个函数
- 使用起来和普通属性一样使用 {{计算属性名}}

注意：计算属性只会计算一次，有缓存，对于 methods 来说，使用几次就调用几次。计算属性的值默认情况下是不能修改的，如果要改，要换成完整写法。

```javascript
computed: {
    计算属性名: {
        get() {

        },
        set() {

        }
    }
}
```

### watch 监视器

监听数据变化，执行一些业务逻辑或异步操作
语法：

- 简单写法：简单类型数据，直接监视

```javascript
watch: {
    数据属性名 (newValue, oldValue) {

    },
    '对象.属性名' (newValue, oldValue) {

    }
}
```

- 完整写法：添加额外配置项

```javascript
watch: {

//   deep: true,  // 加入该配置，表示深度监听，当对象的任意属性改变后，都可以监听到
//   immediate: true // 立即监听（页面刷新），马上执行一次handler函数
// }
obj: {
    handler(val) {
    console.log(val);

    },
    deep: true,
    immeediate: true
}

```

### Vue 生命周期

一个 Vue 实例从创建到销毁的整个过程。
生命周期四个阶段：创建（准备数据）、挂载（渲染页面）、更新、销毁

Vue 生命周期过程中，会自动运行一些函数，被称为生命周期钩子，让开发者可以在特定阶段运行自己的代码

创建阶段：before create、created
挂载：before mount、mounted
更新：before update、updated
销毁：before destroy、destroyed

## Vue3

### 创建 vue3 项目

使用 npm init vue@latest，这一指令将会安装并执行 create-vue

#### 熟悉项目

1. vite.config.js：项目的配置文件基于 vite 的配置
2. package.json：项目包文件，核心依赖项变成了 vue3.x 和 vite
3. main.js：入口文件 createApp 函数创建应用实例
4. app.vue：根组件
   1. 脚本 script 和 template 顺序调整
   2. 默认 template 不在要求唯一根元素
   3. 脚本 script 添加 setup 标识支持组合式 API
5. index.html：单页入口提供 id 为 app 的挂载点

### 组合式 API

1. setup 选项的执行时机：beforeCreate 钩子之前自动执行
2. 定义数据 + 函数，然后以对象方式 return（不使用语法糖）
3. 经过语法糖的封装更简单的使用组合式 API

```vue
<script setup>
const message = 'this is message'
const logMessage = () => {
  console.log(message)
}
</script>

<template>
  <div>
    {{ message }}
    <button @click="logMessage">log</button>
  </div>
</template>
```

#### reactive 和 ref 函数

reactive：接收对象类型数据的参数传入并返回一个响应式的对象
ref：接收简单类型或者对象类型的数据传入并返回一个响应式的对象

```vue
<script setup>
// 1. 导入函数
import { reactive } from 'vue'
import { ref } from 'vue'

// 2. 执行函数 传入一个对象类型的参数
const state = reactive({
  count: 0
})

const setCount = () => {
  state.count++
}

const num = ref(0)
const setNum = () => {
  // 脚本区域修改ref产生的响应式对象数据 比图通过.value属性
  num.value++
}
</script>

<template>
  <div>
    <button @click="setCount">{{ state.count }}</button>
  </div>
  <div>
    <button @click="setNum">{{ num }}</button>
  </div>
</template>
```

#### computed 使用

```vue
<script setup>
import { ref } from 'vue'
import { computed } from 'vue'

const list = ref([1, 2, 3, 4, 5, 6, 7])

const computedList = computed(() => {
  return list.value.filter(item => item > 2)
})
</script>

<template>
  <div>原始响应数组{{ list }}</div>
  <div>计算属性数组 {{ computedList }}</div>
</template>
```

#### watch 使用

immediate：在侦听器创建时立即触发回调，响应式数据变化之后继续执行回调
deep：通过 watch 监听的 ref 对象默认是浅层监听的，直接修改嵌套的对象属性不会触发回调执行，需要开启 deep

```vue
<script setup>
import { ref, watch } from 'vue'

const count = ref(0)
const setCount = () => {
  count.value++
}

// ref对象不需要加.value
watch(
  count,
  (newValue, oldValue) => {
    console.log('count变化了', newValue, oldValue)
  },
  {
    immediate: true
  }
)
</script>
```

精确侦听对象的某个属性变化：

```vue
<script setup>
import { ref, watch } from 'vue'

const state = ref({ count: 0, age: 10 })

watch(
  () => state.value.count,
  (newVal, oldVal) => {
    console.log('count变化了')
  }
)
</script>
```

#### 模板引用

defineExpose：默认情况下<script setup>语法糖下组件内部的属性和方法式不开放给父组件访问的，可以通过 defineExpose 编译宏指定哪些属性和方法允许访问

```vue
<script setup>
import { onMounted, ref } from 'vue'
import TestComm from './TestComm.vue'

const h1Ref = ref(null)
const commRef = ref(null)

onMounted(() => {
  console.log(h1Ref.value)
  console.log(commRef.value)
})
</script>

<template>
  <h1 ref="h1Ref"></h1>
  <TestComm ref="commRef"></TestComm>
</template>
```

```vue
<script setup>
import { ref } from 'vue'

const name = ref('test name')
const setName = () => {
  name.value = 'test new name'
}
// 暴露给父组件
defineExpose({ name, setName })
</script>

<template>
  <div>test组件</div>
</template>

<style lang="scss" scoped></style>
```
