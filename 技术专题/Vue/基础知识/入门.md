# Vue

## 插值表达式{{ }}
插值表达式是一种Vue的模板语法

- 使用的数据必须存在
- 支持的是表达式，而非语句，比如 if、for
- 不能在标签属性中使用{{}}插值

```vue
<div id="app">
    {{uname}}
</div>

<script>
data: {
    uname: 'lao'
}
</script>
```

## 响应式
数据变化，视图自动更新。数据的值会绑定到Vue对象上

## vue指令
vue会根据不同的指令，针对标签实现不同的功能，带有 v-前缀的特殊标签属性

### v-html
类似于innerHTML，如果值中有包含标签的话，也可以正常解析

```vue
<div v-html=str>
    这是一个div
</div>

<script>
data: {
    str: '你是一个<strong>优秀</strong>的boy'
}
</script>
```

### v-show和v-if
v-show
1. 作用：控制元素显示隐藏
2. 语法：v-show = "表达式" 表达式值true显示，false隐藏
3. 切换display: none 控制显示隐藏
4. 频繁切换显示隐藏的场景

v-if
1. 作用：控制元素显示隐藏
2. 语法：v-if = "表达式"  表达式值true显示，false隐藏
3. 原理：基于条件判断，是否创建或移除元素节点
4. 要么显示、要么隐藏，不频繁切换的场景

### v-on
作用：注册事件 = 添加监听 + 提供处理逻辑
语法：
- v-on:事件名 = "内联语句"
- v-on:事件名 = "methods中的函数名"

简写：@事件名

注意：methods函数内的this指向vue实例

### v-bind
作用：动态的设置html的标签属性，比如 src、url、title
语法：v-bind:属性名="表达式"

简写：:src = "url"

### v-for
作用：基于数据循环，多次渲染整个元素
语法：v-for = "(item, index) in 数组"


### v-model
作用：给表单元素使用，双向数据绑定
数据变化 -> 视图自动更新
视图变化 -> 数据自动更新
语法：v-model=""

## 指令修饰符
通过.指明一些指令后缀，不同后缀封装了不同的处理操作

1. 按键修饰符
   1. @keyup.enter: 键盘回车监听
2. v-model修饰符
   1. v-model.trim: 去除首尾空格
3. @事件名.stop → 阻止冒泡
4. @事件名.prevent → 阻止默认行为

## computed计算属性
基于现有的数据，计算出来的新属性。依赖旧的数据变化，自动重新计算。
语法：
- 声明在computed配置项中，一个计算属性对应一个函数
- 使用起来和普通属性一样使用 {{计算属性名}}

注意：计算属性只会计算一次，有缓存，对于methods来说，使用几次就调用几次。计算属性的值默认情况下是不能修改的，如果要改，要换成完整写法。

```vue
computed: {
    计算属性名: {
        get() {

        },
        set() {

        }
    }
}
```

## watch监视器
监听数据变化，执行一些业务逻辑或异步操作
语法：
- 简单写法：简单类型数据，直接监视
```vue
watch: {
    数据属性名 (newValue, oldValue) {

    },
    '对象.属性名' (newValue, oldValue) {

    }
}
```

- 完整写法：添加额外配置项
```vue
watch: {

//   deep: true,  // 加入该配置，表示深度监听，当对象的任意属性改变后，都可以监听到
//   immediate: true // 立即监听（页面刷新），马上执行一次handler函数
// }
obj: {
    handler(val) {
    console.log(val);
    
    },
    deep: true,
    immeediate: true
}

```

## Vue生命周期
一个Vue实例从创建到销毁的整个过程。
生命周期四个阶段：创建（准备数据）、挂载（渲染页面）、更新、销毁

Vue生命周期过程中，会自动运行一些函数，被称为生命周期钩子，让开发者可以在特定阶段运行自己的代码

创建阶段：before create、created
挂载：before mount、mounted
更新：before update、updated
销毁：before destroy、destroyed
