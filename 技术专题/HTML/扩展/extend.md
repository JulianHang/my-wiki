# 扩展

## vscode快捷键

- 快速生成HTML骨架：! + tab 键
- 上下移动代码：Alt + 上下箭头
- 复制代码：Shift + Alt + 上下箭头
- 快速修改多个：Ctrl + d
- 快速写内容：标签 + {实际内容}，比如 div{我是div}



## 什么情况下使用背景图片，什么情况下使用插入图片
不经常更换、用来装饰的通常使用背景图片；产品类的或者经常更换的图片需要使用图片。

## 给a标签设置block，同时设置margin属性，margin区域的地方，鼠标箭头没办法变成手掌，这是什么原理
因为 margin 是元素盒子外部的外边距，不属于 a 标签自身的内容区、内边距区或边框区。
