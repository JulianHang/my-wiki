## Promise
管理异步操作的对象，可以获取成功或失败的结果

```html
<script>
    const p = new Promise((resolve, reject) => {
        setTimeout(() => {
            resolve('xx')
        }, 1000)
    });

    p.then(res => {
        console.log(res);
    }).catch(error => {
        console.log(error);
    })

</script>
```

### Promise状态
一个Promise必然处于以下几种状态
- 待定pending：初始状态，既没有被兑现，也没有被拒绝
- 已兑现fullfilled：意味着操作成功完成，通过resolve修改状态从而触发then回调函数
- 已拒绝rejected：意味着操作失败，通过reject修改状态从而触发catch回调函数

注意：Promise对象一旦被兑现或拒绝，就是已敲定了，状态无法在改变

### Promise链式调用
链式调用：每一个then方法还会返回一个新生成的Promise对象，这个对象可被用作链式调用
then方法的返回值：then方法中的回调函数的返回值，会影响新生成的Promise对象最终状态和结果

```html
<script>
    function getPname() {
        return new Promise((resolve, reject) => {
            setTimeout(() => {
                resolve("p")
            }, 1000)
        })
    }

    const p = getPname();
    p2 = p.then(data => {
        return data;
    })

    p2.then(data => {
        console.log("2", data);
    })


</script>

```


### Promise.all静态方法
集合多个Promise的返回结果时很有用。将多个Promise对象包装成一个新的Promise对象，获取所有的成功结果，或某一个的失败原因



## 回调函数地狱
在回调函数中调用回调函数，形成的代码结构称之为回调函数

缺点：可读性差，异常捕获困难

## async和await
在async函数内，使用await关键字取代then函数，等待获取Promise对象成功状态的结果值。如果不写await的话，获取的是一个Promise对象，加上async关键字，函数返回的是一个Promise对象


## 事件循环eventloop
js是单线程的，为了不让耗时代码阻塞其他代码运行，就设计了事件循环。其中有调用栈、宿主环境（浏览器）、任务队列

### 宏任务与微任务
宏任务：由浏览器环境执行的异步代码，比如setTimeout/setInterval/ajax请求完成事件/用户交互事件
微任务：由JS引擎环境执行的异步代码，比如Promise对象.then()和catch()

注意：Promise本身是同步的，then和catch回调函数是异步的


## Webpack
webpack是一个用于现代js应用程序的静态模块（html、js、css）打包工具

### 使用Webpack
参考案例中的webpack
1. 新键项目文件夹，初始化包环境，npm init -y
2. 新键src源代码文件夹（书写代码）
3. 下载webpack webpack-cli到项目
4. 项目中运行工具命令，采用自定义命令的方式
5. 自动产生dist分发文件夹（压缩和优化后，用于最终运行的代码）

### 修改Webpack打包入口和出口
webpack.config.js 

1. 项目根目录，新键webpack.config.js配置文件
2. 导出配置对象，配置入口，出口文件路径
```javascript
// webpack.config.js
const path = require('path')

module.exports = {
    entry: path.resolve(__dirname, 'src/main.js'),
    output: {
        path: path.resolve(__dirname, "dist"),
        filename: 'app.js'
    }

}

```
执行流程：

1. npm run build 启动 webpack CLI（它运行在 Node.js 中）。
2. CLI 用 Node.js 加载 webpack.config.js。
3. webpack 根据配置解析 src 里的模块并打包
