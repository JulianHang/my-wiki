# Hello-Agents

## 资料入口

- 在线阅读：https://datawhalechina.github.io/hello-agents/#/
- GitHub：https://github.com/datawhalechina/Hello-Agents

## 资料定位

Datawhale 出品的系统性 AI Agent 教程，覆盖基础概念、经典范式、框架实践、高级主题和综合案例。

它更适合作为 AI Agent 的主线教材，而不是零散文章收藏。

## 重点内容

- 智能体定义、类型、发展历史。
- 大语言模型基础。
- ReAct、Plan-and-Solve、Reflection 等经典范式。
- Coze、Dify、n8n 等低代码平台。
- AutoGen、AgentScope、LangGraph 等框架实践。
- 从零构建 Agent 框架。
- 记忆、RAG、上下文工程、MCP、A2A、ANP。
- Agentic RL、智能体评估。
- 智能旅行助手、自动化深度研究智能体、赛博小镇等综合案例。

## 我的使用方式

建议按章节推进，不要只收藏链接。

每读完一章，至少沉淀一篇自己的笔记：
- 这一章解决什么问题。
- 核心概念是什么。
- 哪些内容能用于自己的项目。
- 有哪些暂时不需要实践。
